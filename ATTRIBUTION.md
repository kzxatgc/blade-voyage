# Asset Attributions & Licenses

This document records credits for assets used in this project.

## 1. Treasure Hunters Sprite Pack

- **Asset Type**: Backgrounds, clouds, grass tiles, dialogue effects, UI, mobile controls, and shooter traps
- **Asset Name**: Treasure Hunters
- **Author / Creator**: Pixel Frog
- **Source Link**: https://pixelfrog-assets.itch.io/treasure-hunters
- **License**: CC0 1.0 Universal (Public Domain) / Free for Personal & Commercial Use
- The inline splash prompt displays `OPEN` using the shared Big Text bitmap font (`font.png` and `font.fnt`), also used by the settings UI. Its interactive chest uses the Merchant Ship Chest Idle and Unlocked frames.
- The settings overlay panel is composed from the top-left 3x3 tile block in `Wood and Paper UI/Sprites/Yellow Board/Yellow Board (guide).png`, using tile order `0 1 1 2 / 3 4 4 5 / 6 7 7 8`.
- The in-game water uses `Palm Tree Island/Sprites/Background/Additional Water.png`; its small, medium, and big Water Reflect highlights use all four source frames and animate at the pack's 10 FPS.
- The red potion drop uses seven `Red Potion (7 items)` animation frames.
- The blue Frenzy Potion uses seven `Blue Potion` animation frames.
- The green shield potion uses seven `Green Bottle` animation frames.
- The Level Select cards use frame 1 of the Wood and Paper UI Yellow Button sprites, with numerals recolored to match its `#33323D` border and thickened with one-pixel dilation.
- The Level Select navigation controls use the same button sprite with the Vecteezy Pixel Art Red Arrow, background removed, rotated rightward, and recolored to match its `#33323D` border; the previous-page arrow is mirrored. The supplied Vecteezy Free License notice requires credit to [Vecteezy.com](https://www.vecteezy.com/).
- The health-potion pickup effect uses four `Potion Effect (4 items)` animation frames.
- The Frenzy pickup effect uses gold recolors of those four `Potion Effect (4 items)` frames.
- The cannon trap uses the Shooter Traps collection's Cannon Idle, Cannon Fire, Cannon Fire Effect, Cannon Hit, Cannon Destroyed, Cannon Ball Idle, Cannon Ball Destroyed, and Cannon Ball Explosion animations.
